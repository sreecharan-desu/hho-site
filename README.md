# hho-site

public website for helping hands organization: about, announcements, current fundraising, urgent help, stories of impact and a photo gallery.

## stack

next.js 15 · react 19 · tailwind css 4 · framer motion · typescript

## run locally

```bash
npm install
npm run dev
npm run build && npm start
```

## env

none in code today. page content is static data in `lib/api.ts`. [SETUP.md](SETUP.md) lists variables for planned admin features.
